# 규칙 참조

모든 결과에는 규칙 코드, 심각도, 입력 파일의 줄 번호(1부터)가 있습니다.
`error` 는 종료 코드를 1로 만들고, `warning` 은 `--fail-on warning` 일 때만 그렇습니다.
`--ignore 코드[,코드]` 로 코드를 뺄 수 있습니다.

| 코드 | 심각도 | 의미 | 고치는 법 |
|---|---|---|---|
| J001 | error | 줄이 올바른 JSON(또는 UTF-8)이 아닙니다. 다음 줄부터 검사를 계속합니다. | 줄을 고치거나 지웁니다. |
| U001 | warning | `messages`·`conversations` 레코드가 아니어서 건너뜁니다. 또는 파일에 레코드가 하나도 없습니다(빈 파일, 빈 줄만 있는 파일). | 형식을 바꾸거나 파일에서 뺍니다. 빈 파일이면 앞 단계를 확인합니다. |
| S001 | error | 도구의 `parameters` 가 올바른 JSON Schema 가 아니거나, 해석할 수 없는 `$ref` 가 있거나(참조는 내려받지 않습니다), `tools` 모양이 틀렸습니다. `tool_calls` 가 목록이 아니거나 메시지·호출이 객체가 아닌 경우도 해당합니다. 그 도구의 호출은 검증하지 않습니다. | 스키마를 고칩니다. 메시지의 `path`·`keyword` 를 봅니다. |
| T001 | error | 호출한 도구가 레코드의 `tools` 에 없습니다. | 도구 정의를 추가하거나 호출 이름을 고칩니다. |
| T002 | error | 도구 호출이 있는데 `tools` 가 없습니다(레코드당 한 번). | `tools` 를 넣습니다. |
| V001 | error | 호출 인자가 도구의 JSON Schema 를 위반합니다. 위반마다 한 건이며 `json_path` 와 실패한 `keyword`(`enum`, `required`, `type`, `additionalProperties` 등)가 붙습니다. | 인자나 스키마를 고칩니다. |
| A001 | error | `arguments` 문자열이 올바른 JSON 이 아니거나, `arguments` 가 없거나 null 입니다. | 올바른 JSON 으로 만듭니다. |
| A002 | error | `arguments` 가 이중 인코딩되어 있습니다. JSON 문자열을 풀어도 다시 문자열입니다. | 한 번만 인코딩합니다. |
| A003 | warning | 한 레코드에 문자열·객체 `arguments` 가 섞여 있습니다. | 데이터셋 전체에서 한 가지로 통일합니다. |
| P001 | error | 호출 뒤에 대화가 이어지는데 도구 응답이 없습니다. 레코드의 **마지막** 메시지가 호출이면 그 호출이 학습 정답(OpenAI 파인튜닝 형식)이므로 보고하지 않습니다. | 응답을 추가하거나 호출을 뺍니다. |
| P002 | error | 도구 응답에 짝이 되는 호출이 없습니다. | id 를 고치거나 응답을 뺍니다. |
| P003 | error | 한 레코드에 같은 호출 id 가 두 번 나옵니다. | id 를 고유하게 만듭니다. |
| P004 | warning | 일부 호출에만 id 가 있습니다. id 가 하나도 없는 레코드는 순서로 짝을 맞추고 보고하지 않습니다. | 빠진 id 를 채웁니다. |

## 종료 코드

`0` 선택한 수준에서 문제 없음, `1` 문제 발견, `2` 도구 오류(사용법, 읽거나 쓸 수 없는 파일, 내부 오류)입니다.

## 호출과 응답의 짝

- 레코드의 호출이나 응답 중 하나라도 id 가 있으면 id 로 짝을 맞춥니다.
- 그렇지 않으면 순서로 맞춥니다(첫 응답이 가장 오래된 열린 호출에 대한 응답입니다).
- ShareGPT(LLaMA-Factory)에서는 `observation` 턴 하나가 바로 앞 `function_call` 턴의 모든 호출에 답합니다.

## 형식

| 형식 | 감지 | 비고 |
|---|---|---|
| OpenAI / HF / TRL / Axolotl | `messages` 목록 | `arguments` 는 JSON 문자열(OpenAI) 또는 객체(HF)이고, `tools` 는 목록이나 JSON 문자열일 수 있습니다. |
| ShareGPT (LLaMA-Factory) | `conversations` 목록 | `function_call` 턴(객체, 병렬 호출은 배열)과 `observation` 턴입니다. |

모든 형식에 같은 규칙이 적용됩니다.
